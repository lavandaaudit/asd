# IBONARIUM: KYIV — THE LAST SIGNAL

**Open world survival у стилі 16-bit Sega Mega Drive.** Один великий відкритий Київ:
Оболонь, Поділ, Старе місто, Хрещатик, Майдан, Печерськ, Києво-Печерська Лавра,
Батьківщина-Мати, Лівий берег, Гідропарк, промзона Дарниця, метро і Дніпро з мостами.

- Ізометрія 2:1, CRT 320×224 — як на Mega Drive
- **Графіка: рендери Kenney City Kits (Commercial / Industrial / Suburban / Roads, CC0)** —
  3D-моделі Kenney спроєктовані в тайлову сітку гри 32×16 (70 варіантів будівель,
  17 типів доріг з розміткою, 17 пропсів), персонажі та локації-домінанти намальовані
  кодом у палітрі Kenney. Працює офлайн, ліцензійно чисто
- 13 сюжетних місій, інтегрованих у відкритий світ (не коридорні рівні)
- 8 типів заражених: WALKER, RUNNER, SCREAMER, BRUTE, BLIND, CRAWLER, GUARDIAN, ALPHA
- Авто: ВАЗ-2101, Daewoo Lanos, Skoda, мікроавтобус, вантажівка (пальне, пошкодження, шум)
- Схованки, склад, крафт, виживання (їжа / вода / медикаменти / **тушонка / енергетик /
  протигаз** — промзона без протигаза отруйна), день-ніч, ліхтар
- 5 NPC з торгівлею та історіями (Валентина, Оля, Сергій, **Патон на мосту, Ганя**)
- Компас N/E/S/W, мінімапа, велика карта Києва з % дослідження, радіосигнали
- **Повний екран**: кнопка ⛶ / `V` / подвійний клік по екрану; на мобільних —
  фолбек-режим на все вікно
- **Мобільна версія**: екранний аналоговий джойстик + кнопки E/ATK/MAP/BAG/LGT/RUN
  (RUN — перемикач бігу), керування з'являється тільки в грі

## Як грати локально

```bash
cd ibonarium-kyiv
python3 -m http.server 8000
# відкрий http://localhost:8000
```
Подвійний клік по index.html теж працює (немає запитів до сервера).

## Деплой на GitHub Pages (2 хвилини)

1. Створи репозиторій на GitHub (наприклад `ibonarium-kyiv`).
2. Завантаж у корінь репозиторію вміст цієї папки:
   `index.html`, `style.css`, папки `js/` і `assets/`, `.nojekyll`
   (або просто перетягни zip у GitHub web-інтерфейс).
3. **Settings → Pages → Build and deployment → Source: `Deploy from a branch`**
4. Branch: `main`, папка: `/ (root)` → **Save**.
5. Через ~1 хвилину гра буде на `https://ТВІЙ_НІК.github.io/ibonarium-kyiv/`.

> `.nojekyll` у комплекті — щоб GitHub не чіпав шляхи до `js/` і `assets/`.

## Керування

| Клавіша | Дія |
|---|---|
| WASD / ←↑↓→ | рух у 8 напрямках |
| SHIFT | біг (витривалість) |
| E | взаємодія: лут, схованки, метро, авто, місії, NPC |
| SPACE | атака / постріл / сигнал в авто |
| Q або 1–4 | мачете / пістолет / граната / аптечка |
| G | кинути гранату |
| M / I | рюкзак і крафт |
| TAB | велика карта Києва |
| F | ліхтар (уночі без нього — темрява) |
| **V / ⛶ / dblclick** | **повний екран** |
| ESC | пауза |

В авто: **W/S** — газ/гальмо, **A/D** — повороти, **E** — вийти, **SPACE** — сигнал (шум притягує заражених).
На телефоні: лівий джойстик — рух, кнопки справа; **RUN** вмикає біг як перемикач.
Десктоп-тест тач-керування: `?touch=1` у адресі.

## Слот Sega Mega Drive / Genesis (EmulatorJS)

На сторінці під консоллю є слот ROM: обери свій файл `.md / .bin / .gen / .smd / .zip` —
підвантажиться ядро **Genesis Plus GX** через CDN [EmulatorJS](https://emulatorjs.org) (безкоштовний, open-source).
На мобільних EmulatorJS автоматично показує свій віртуальний геймпад.
ROM-файли до збірки не входять — використовуй лише власні легальні копії.

## Асети та ліцензії

Будівлі, дороги і пропси гри — це **рендери безкоштовних наборів
[Kenney](https://kenney.nl) City Kits (CC0)**: 3D-моделі з OBJ+колормапа
переведені у піксель-ізометрію скриптами в `tools/` (рендер у проєкцію гри 2:1,
тайли 32×16, апокаліпсис-постобробка). Персонажі, зомбі, авто, предмети,
6 локацій-домінант і тайли землі малюються кодом (`js/sprites.js`, `js/landmarks.js`)
у палітрі Kenney (#61cb8b, #515566, #8e95b3, #6794d9, #ffc044, #ff7e44…).

| Пак | Ліцензія | Використання |
|---|---|---|
| Kenney — City Kit (Commercial) | CC0 | будівлі офісів/панельки, вежі |
| Kenney — City Kit (Industrial) | CC0 | заводи, контейнери, tank/chimney |
| Kenney — City Kit (Suburban) | CC0 | будинки старого міста, дерева, паркани |
| Kenney — City Kit (Roads) | CC0 | усі 16 масок доріг + категорії |
| SmallScaleInt — Zombie City HD Isometric Tileset | — | **платний $29.99** (не використано) |

Перегенерувати ассети: `python3 tools/build_assets.py` (потрібні zip-и Kenney,
розпаковані в `tools/kenney_src/extracted/`, і Pillow).

## Технічна архітектура

```
index.html      — сторінка-«консоль» IK-1601: картридж, CRT, HUD, слот ROM
style.css       — оболонка консолі, IBONARIUM DARK HUD, тач-керування, full screen
js/palette.js   — палітра Kenney 9-bit + піксель-хелпери (IB.*)
js/audio.js     — WebAudio чіптюн-SFX + двигун авто
js/sprites.js   — спрайти: тайли, зомбі, гравець, NPC-варіанти, авто, предмети
js/assets.js    — завантажувач PNG-рендерів Kenney (assets/)
js/kenney.js    — підміна будівель/доріг/пропсів на Kenney-рендери (+ фолбек)
js/landmarks.js — 6 домінант: Монумент, Лавра, Софія, Золоті Ворота, Колона, Андріївська
js/world.js     — карта 224×224: Дніпро, мости, пагорби, 13 районів, об'єкти
js/ents.js      — Марко, заражені (8 типів), авто, кулі, пожежі, лут
js/sys.js       — 13 місій, радіовежі, схованки, крафт, збереження (localStorage)
js/gfx.js       — ізометричний рендер, нічне світло, мінімапа, компас, велика карта
js/main.js      — цикл, керування, меню, HUD, повний екран, EmulatorJS
assets/         — PNG-рендери Kenney City Kits (bld_*, road_*, пропси)
tools/          — скрипти рендеру ассетів + ліцензія Kenney (CC0)
```

Прогрес зберігається в `localStorage` (автозбереження на нову добу та після місій,
ручне — у схованках). Світ 224×224 тайлів живе в типізованих масивах; будівлі й
пропси малюються з відсіканням по камері — 60 FPS у браузері.

## Дорожня карта (фаза 2 — справжня ROM)

Сторінка вже готова прийняти справжню ROM-ку через слот EmulatorJS. Наступний крок —
порт механік на **SGDK (C, 68K)**: тайлова карта секторів, Sprite Engine, палітра 4 октетів,
компресія мапи. Цей проєкт виступає playable-прототипом і дизайн-документом для нього.
